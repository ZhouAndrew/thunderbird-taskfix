# Thunderbird TaskFix

Experimental user-local Thunderbird patch tooling for task workflows.

Current development targets:

- reliable multi-select completion for recurring CalDAV VTODOs;
- batch Category editing;
- batch Status editing;
- no in-place modification of the distro Thunderbird;
- real Thunderbird + Radicale acceptance testing before a release is called verified.

Development work is done on feature branches.
